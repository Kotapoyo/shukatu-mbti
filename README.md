# 企業MBTI

## 概要

企業MBTIは、就活の手間を減らしたい新卒学生と、人手の確保を優先する企業を引き合わせる、モバイル対応の就活アプリです。

学生の最低限の希望条件と企業の募集条件を照合し、条件を満たす求人から、性格傾向と企業の働き方・職場特性に合う業界や企業を提案します。学生の企業探し・比較・応募までの負担を減らし、企業には募集条件に合う学生との接点を提供することで、人手不足の改善を目指します。また、双方の条件や働き方に関する認識のずれを軽減します。

現在は企画段階です。以下の機能は開発予定であり、実装済み機能を示すものではありません。

- 対象：就活を面倒に感じる新卒学生、人手の確保を優先する企業
- 企画・開発体制：チーム児玉（児玉・松本・田代・村田の4名）
- 分担する領域：企画、画面、診断処理、企業情報。担当者の割り当ては未定
- 予算：未定。開発・サーバー・データ取得・配信にかかる費用を算定予定

## 主な機能

- **プロフィール・希望条件の登録**：学生のプロフィールと最低限の希望条件を登録する。
- **企業による情報登録**：企業が自社の働き方・福利厚生を登録できるようにする。
- **サブスクリプション登録企業の優先表示**：サブスクリプションに登録した企業を上位に表示する。
- **求人の絞り込み**：地域、給与、休日、福利厚生などの条件で求人を絞り込む。
- **性格傾向と職場特性の照合**：短い質問から性格傾向を把握し、企業の働き方・職場特性と照合する。
- **業界・企業の提案**：最低条件を満たす求人から、傾向に合う業界と企業1〜2社を提案する。
- **企業詳細・提案理由の表示**：企業情報、診断理由、未確認事項、情報の出典・確認日を表示する。
- **応募先への案内**：公式応募先URLを表示する。
- **該当する求人がない場合の対応**：学生本人が希望条件を再設定できるようにする。

勤務地・給与などの最低条件を優先し、未確認の項目は明示します。サブスクリプション登録企業の優先表示は、この最低条件を優先する方針に沿って設計します。具体的な表示順位の決め方や、性格傾向との相性を順位に反映する方法は未定です。サブスクリプションの料金・契約期間・決済方法は未定です。性格診断は企業選びの参考として扱い、能力や採用可否を断定する用途は対象外とします。

地域の詳細検索、口コミ、履歴書・選考状況の管理は追加候補です。初期開発に含めるかは未定です。

## テスト・確認方法

テスト・lint・ビルドのツールと実行コマンドは未定です。開発時には、以下の動作を確認します。

- プロフィール・希望条件を登録し、求人の絞り込みに反映できること
- 企業が自社の働き方・福利厚生を登録できること
- 最低条件を満たす求人から企業が提案されること
- 最低条件を満たす候補の表示で、サブスクリプション登録企業の優先表示が反映されること
- 質問への回答に応じた診断結果と、提案理由が表示されること
- 企業情報の出典・確認日と、未確認事項が表示されること
- 該当する求人がない場合、本人が希望条件を再設定できること
- 公式応募先URLが表示され、リンク先へ移動できること
- スマートフォンで入力や結果の確認ができること
