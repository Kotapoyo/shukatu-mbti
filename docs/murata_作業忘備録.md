# murata 作業忘備録（2026-10-27）

- 架空学生用のメール・パスワード認証を Better Auth とローカル MySQL に接続した。
- ログイン中の学生が提案企業を保存し、「提案企業」画面で一覧を確認できるようにした。
- 診断回答と架空企業の11項目の評価値との差を集計し、差が小さい順に最大2社を提案するようにした。
- デモ企業の募集条件と11項目の5段階評価を、画面から登録・編集できるようにした。
- デモ企業と学生プロフィールを、利用者IDごとに同じブラウザーへ保存するようにした。
- 希望勤務地と最低月給を提案の前に判定し、候補0社から条件を変更して再判定できるようにした。
- 登録したデモ企業と既存の架空企業を提案結果から保存し、保存企業一覧で確認できるようにした。
- 保存APIでも希望条件を用いて候補を再判定し、条件によって順位が上がった企業を保存できるようにした。
- 型検査、ビルド、対象テスト9件、実ブラウザーの登録・診断・保存・0社からの再判定を確認した。
- デモ企業とプロフィールはブラウザー内の保存に限定している。実在企業の登録、休日・福利厚生による絞り込み、企業詳細画面は今後の実装対象である。
